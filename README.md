## Endpoints

Below are the links that are used in the main app for the requests.

| Link | Description |
| ---- | ----------- |
| [Base](https://agapis-lapis-proxy.onrender.com/) | This is the base link for the rest of the requests. Using the link as-is will yield a simple check if the server is active. |
